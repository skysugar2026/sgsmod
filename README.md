# 末日三国终章 · 10000 武将版

单文件 HTML 三国杀武将图鉴，收录 **10000** 名武将。

## 在线游玩

启用 GitHub Pages 后访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

或直接打开武将图鉴：

```
https://<你的用户名>.github.io/<仓库名>/末日三国终章.html
```

## 功能

- 10000 名武将，支持按势力 / 稀有度 / 类型筛选
- 关键词搜索（技能名、技能文本、称号均可命中）
- 战力排序、翻页浏览
- 武将详情页：技能全文、复杂度雷达图
- 收集进度记录（localStorage 本地保存）

## 数据说明

- 原版 3040 名武将数据**逐字节保留**，未做任何修改
- 新增 6960 名按原版生成规律扩充（技能点档位、cost 上限、
  complex 与 cost 的对应关系、正文长度随 cost 递增等）
- 全量数据经校验：ID 连续、字段自洽、分布一致

## 技术实现

单文件，无任何外部依赖，可离线打开。

数据采用列式存储 + 字典池 + gzip 压缩后内嵌，
10000 名武将的完整数据压缩至约 1 MB。
